MySQL Console · 系统架构 v3.5

零框架 Python 标准库 http.server + PyMySQL ｜ 浏览器访问 127.0.0.1:8090 ｜ 本机无需安装 MySQL

核心功能

  • • 实时监控 + ECharts 数据看板(健康评分/InnoDB/复制)
  • • 备份/还原:实时进度、gzip 压缩、历史与文件下载
  • • 定时备份双引擎(内置调度 + 系统计划任务)
  • • MySQL 用户增删改授权(root 保护)

架构特点

  • • 零框架:Python 标准库 http.server,依赖仅 pymysql+cryptography
  • • 被管库可远程,部署机无需 MySQL;客户端工具动态探测
  • • 跨平台:Windows / Linux / macOS(原生对话框全覆盖)
  • • 双后端存储:轻量 SQLite / 全量 MySQL 系统库

运维能力

  • • 三步首流向导 + 一键安装 + systemd 服务化
